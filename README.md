# כלי מספור אלבום תמונות 📸

כלי מקומי ופשוט להכנת קובץ PDF של אלבום תמונות לשליחה ללקוחות לצורך **תיקונים**.

הכלי מקבל PDF של אלבום, שבו כל עמוד הוא **כפולה** (spread), ומייצר קובץ PDF חדש שבו:

1. נוסף **קו אנכי לבן** בדיוק במרכז הכפולה (50% מרוחב העמוד), לכל גובה העמוד.
2. כל התמונות הנפרדות בכפולה מזוהות אוטומטית.
3. כל תמונה מקבלת **מספר** בתוך עיגול לבן (עם שקיפות קלה, מסגרת שחורה ומספר שחור בולט).
4. המספור מתחיל מ-1 בכל כפולה ו**מתאפס** בכפולה הבאה.
5. הסדר הוא לפי **קריאה חזותית**: משמאל לימין, ומלמעלה למטה כשיש כמה שורות.

**הקובץ המקורי לעולם אינו משתנה.** נוצר קובץ חדש בשם `שם-הקובץ_numbered.pdf` בתיקיית `output`.
מידות העמוד, יחס התמונה, הרזולוציה, סדר העמודים ואיכות התמונות נשמרים ללא שינוי.

## 🖥️ למי שלא מתכנתת – התקנה והפעלה ב-3 צעדים (Mac)

### צעד 1 – התקנה חד-פעמית
לחצי **פעמיים** על הקובץ `install_mac.command`.
ייפתח חלון שחור (Terminal) שיתקין את כל מה שצריך. חכי להודעה **"ההתקנה הושלמה בהצלחה"** וסגרי את החלון.

> אם מופיעה הודעה ש-Python לא מותקן – התקיני אותו מהאתר הרשמי
> [python.org/downloads/macos](https://www.python.org/downloads/macos/) (גרסה 3.11 ומעלה),
> ואז הריצי שוב את `install_mac.command`.

> **הערה בנוגע לאבטחת Mac:** בפעם הראשונה שלוחצים על קובץ `.command`, ייתכן שה-Mac יציג
> אזהרה. במקרה כזה: לחצי קליק ימני על הקובץ → **Open** → **Open**. צריך לעשות זאת פעם אחת בלבד.

### צעד 2 – שמות התיקיות
בתיקיית הכלי יש ארבע תיקיות:
- **input** – כאן שמים את קובצי ה-PDF של האלבומים.
- **output** – כאן נוצרים קובצי ה-PDF הסופיים ללקוח.
- **previews** – כאן נוצרות תמונות התצוגה המקדימה (במצב REVIEW).
- **debug** – כאן נשמר קובץ יומן (`process.log`) שעוזר לאיתור תקלות.

### צעד 3 – הפעלה
לחצי **פעמיים** על `run_app.command`. ייפתח חלון פשוט שבו:

1. בוחרים את **קובץ ה-PDF** של האלבום.
2. בוחרים **תיקיית פלט** (ברירת המחדל: תיקיית `output`).
3. מסמנים האם **כל עמוד הוא כפולה**, או ש**צריך לחבר כל שני עמודים** לכפולה אחת.
4. מסמנים האם **לכלול תמונת רקע** מלאה במספור.
5. בוחרים מצב **AUTO** (יצירת PDF מיד) או **REVIEW** (תמונות בדיקה לפני).
6. לוחצים על הכפתור הירוק **"צור PDF ללקוח"**.

בסיום תופיע הודעת הצלחה עם מיקום הקובץ, ואפשר לפתוח את התיקייה בלחיצה.

## ⌨️ שימוש דרך שורת הפקודה (למתקדמים)

```bash
python3 album_reviewer.py input/my_album.pdf
```

### אפשרויות

| אפשרות | משמעות | ברירת מחדל |
|---|---|---|
| `--review` | מצב REVIEW: יצירת תמונות תצוגה מקדימה לכל כפולה במקום PDF סופי | כבוי |
| `--manual JSON` | מצב MANUAL: קובץ JSON עם מיקומי תמונות ידניים | — |
| `--line-width` | עובי הקו המרכזי (בנקודות PDF) | יחסי לרוחב העמוד |
| `--label-size` | מקדם גודל לעיגול ולמספר (1.0 = רגיל, 1.5 = גדול יותר) | 1.0 |
| `--min-image-area` | שטח מינימלי של תמונה כשבר משטח העמוד (0.015 = 1.5%) | 0.015 |
| `--dpi` | רזולוציית רינדור לזיהוי החזותי | 200 |
| `--include-background` | לכלול תמונת רקע מלאה במספור | כבוי |
| `--pair-pages` | לחבר כל שני עמודים עוקבים לכפולה אחת לפני העיבוד | כבוי |

### דוגמאות

```bash
# יצירת תצוגות מקדימה לבדיקה
python3 album_reviewer.py input/my_album.pdf --review

# כשכל עמוד ב-PDF הוא דף בודד (ולא כפולה)
python3 album_reviewer.py input/my_album.pdf --pair-pages

# עיגולים גדולים יותר וקו עבה יותר
python3 album_reviewer.py input/my_album.pdf --label-size 1.4 --line-width 4
```

## 🔍 שלושת מצבי העבודה

1. **AUTO** – זיהוי ומספור אוטומטיים, ויצירת ה-PDF הסופי.
2. **REVIEW** – יצירת תמונות `previews/…png` לכל כפולה, עם המלבנים והמספרים שזוהו,
   כדי לבדוק את התוצאה **לפני** יצירת ה-PDF הסופי.
3. **MANUAL** – סיפוק קובץ JSON עם מיקומי תמונות ידניים, לכפולות שבהן הזיהוי האוטומטי נכשל.

### פורמט קובץ ה-JSON למצב MANUAL

הקואורדינטות הן ביחידות **נקודות PDF** (points), והמפתח הוא **מספר הכפולה** (מתחיל מ-0):

```json
{
  "pages": {
    "0": [[50, 50, 500, 700], [560, 50, 1080, 700]],
    "5": [[30, 40, 540, 720]]
  }
}
```

כל מלבן הוא `[x0, y0, x1, y1]` – פינה שמאלית-עליונה ופינה ימנית-תחתונה.
כפולות שאינן מופיעות בקובץ יעברו זיהוי אוטומטי כרגיל.

## 🧠 איך עובד הזיהוי

הכלי מנסה שני נתיבים:

1. **נתיב אובייקטים (PyMuPDF):** בודק אם התמונות קיימות כאובייקטים נפרדים ב-PDF
   (`get_image_info` / bounding boxes), מזהה מופעים נפרדים ומסיר כפילויות.
2. **נתיב חזותי (OpenCV) – fallback:** אם העמוד משוטח (תמונת raster אחת מלאה),
   העמוד מרונדר זמנית ב-200 DPI ומזוהים אזורי התמונות באמצעות:
   - זיהוי רקע/מרווחים לבנים (gutters) בין התמונות;
   - זיהוי קצוות ו-contours;
   - פיצול תמונות צמודות לפי "תפרים" בהירים דקים;
   - סינון אזורים קטנים מדי ואיחוד/הסרה של מלבנים כפולים.

**סינון:** אזור שתופס פחות מ-1.5% משטח העמוד מתעלמים ממנו כברירת מחדל
(ניתן לשינוי עם `--min-image-area`). טקסט קטן ואייקונים זעירים אינם ממוספרים.

**סדר המספור:** תמונות שמרכזן האנכי קרוב (בטווח של ~12% מגובה העמוד) נחשבות לאותה
שורה וממוינות משמאל לימין; שורות ממוינות מלמעלה למטה.

> 💡 בכפולה מורכבת שבה הזיהוי אינו מושלם, מומלץ להריץ תחילה במצב **REVIEW**,
> לבדוק את התמונות בתיקיית `previews`, ובמקרה הצורך להשתמש במצב **MANUAL**.
